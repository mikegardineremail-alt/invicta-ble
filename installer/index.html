Invicta Bridge installer

Puts the battery-logger software (version 1.3.4) on the Altronics Z6433 ESP32-S3 board. Use Chrome or Edge on a computer.

1.2.2: updates itself. Every 6 hours it checks this page and installs newer firmware over WiFi (switch Auto-update on the bridge page). Boards on 1.2.1 or older need this install once.

New in 1.2.0: it can also listen to a Victron SmartShunt and a Smart BatteryProtect (it only reads their Bluetooth broadcasts and never sends them anything), and logs each one to its own Google Sheet. The software contains no Victron keys. After installing, type each device's MAC address, encryption key and sheet URL into the bridge's own page. Leave them empty if you don't use Victron. Your Invicta sheet setup is unchanged.

  1. Plug the board into the computer with a USB-C data cable, using the port labelled UART (or COM).
  2. Click the button below, pick the port that appears (CP2102 / "USB to UART"), then click Install.
  3. When it finishes it asks for your WiFi. Choose your home WiFi and type its password.
  4. Click Visit device to open the bridge's own page.
  5. Already running 1.1.x? You can also update over WiFi: on the bridge page use OTA Update with invicta-bridge.ota.bin. Press Upload now first and wait until Rows waiting to upload is 0.
This browser can't do it. Please use Chrome or Edge on a Windows, Mac or Linux computer. This page must be opened over https.

No port listed? On Windows, install the CP210x driver, or try the other USB-C port. Still stuck? Hold the BOOT button, tap RST, let go of BOOT, and try again.
